# Local review checklist

1. Open a pull request against the default branch.
2. Confirm that the GitHub App receives the pull request event.
3. Wait for the enterprise-review check to finish.
4. Read its summary and any inline findings on the reviewed commit.
5. Resolve findings and push a new commit for another review.
6. Ask a human reviewer to assess the change before merging.

An incomplete automated review must not be treated as a passing result.
This document introduces no executable code or infrastructure resources.
